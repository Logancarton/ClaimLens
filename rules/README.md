# Rules

This directory is the single repository home for human-reviewable billing/payer rule definitions.

- `medicare/` — Medicare-specific rules.
- `arizona/` — Arizona-specific requirements that materially affect ClaimLens behavior.
- `commercial/` — commercial payer overlays, separated by payer as they are added.

See `docs/RULE_GOVERNANCE.md` before adding production rules.

Prompts are not rules. Model output is not a rule source.
